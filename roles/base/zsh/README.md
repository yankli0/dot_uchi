# zsh

- Shared bindings, aliases, plugins and local history; sets Zsh as login shell.
- Select with `zsh` or `terminal`; includes Starship and terminal utilities.
- Override `zsh_packages` for distribution plugin packages.
- Activates mise/zoxide when installed; prefers Neovim, otherwise Vim.
- Native prompt configuration belongs to the Starship role.
- No enrollment or listening ports; credentials and history remain local.
