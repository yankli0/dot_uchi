# ai_tools

- Install Claude Code, OpenCode, pi and Unsloth Studio with their upstream installers.
- Each installer runs only when its binary is missing; `ai_tools_selected` narrows the set.
- OpenCode installs under `~/.opencode/bin`; the role links it into `~/.local/bin`.
- Sign-in, provider keys and model downloads stay explicit. No ports are opened here.
